MAFIA STATE RP — SITO WEB V2
==============================

MODIFICA IMPORTANTE
- Rimossa completamente la categoria CARTELLI.
- Le categorie sono ora: MAFIE, GANG, OFFICINE, BAR, RISTORANTI.
- Ogni categoria è cliccabile.
- Cliccando una categoria si apre una finestra con l'elenco delle attività.
- I dati delle attività sono modificabili nel file script.js.

COME APRIRE
Apri index.html nel browser.

COME AGGIUNGERE UN'ATTIVITÀ
Apri script.js e cerca "directoryData".
Esempio:
{
  nome: "Vice Bar",
  zona: "Downtown",
  descrizione: "Il punto di ritrovo della notte.",
  immagine: "images/bar-01.jpg"
}

Per ora le immagini sono opzionali. Se il file immagine non esiste,
il sito mostra un riquadro elegante senza rompere la pagina.

CATEGORIE DISPONIBILI
- mafie
- gang
- officine
- bar
- ristoranti

Quando avrai i nomi reali delle attività del server, sostituisci gli esempi
in script.js e inserisci le immagini nella cartella images.
